## 地图展示

地图展示是系统的核心功能，基于 Mapbox GL 实现电网设备的地理信息可视化。

### 功能特点

| 功能 | 说明 |
|------|------|
| 变电站展示 | 在地图上显示变电站位置、电压等级、运行状态 |
| 输电线路 | 展示输电线路走向、连接关系、负载情况 |
| 台区显示 | 显示配电台区范围、用户数量、负载率 |
| 区域选择 | 快速定位到指定省市区域 |
| 图层控制 | 切换变电站/线路/台区图层的显示与隐藏 |

### 操作说明

1. **查看设备详情**：点击地图上的设备图标，右侧弹出详情面板
2. **查看运行曲线**：在详情面板点击"查看曲线"，展示历史运行数据
3. **查看拓扑关系**：点击"查看拓扑"，展示设备的连接关系
4. **区域定位**：使用顶部区域选择器，快速定位到目标区域
5. **图层切换**：使用左侧控制面板，切换图层显示

### 设备状态说明

| 状态 | 颜色 | 说明 |
|------|------|------|
| 运行中 | 🟢 绿色 | 设备正常运行 |
| 停运 | 🔴 红色 | 设备停止运行 |
| 检修 | 🟡 黄色 | 设备正在检修 |

## 数据统计

数据统计仪表盘提供电网运行数据的可视化展示。

### 统计指标

| 指标 | 说明 |
|------|------|
| 变电站数量 | 系统中变电站总数 |
| 输电线路数量 | 系统中输电线路总数 |
| 台区数量 | 系统中配电台区总数 |
| 用户总数 | 供电用户总数 |
| 线路总长度 | 输电线路总长度（公里） |
| 设备运行率 | 运行中设备占比 |
| 告警处理率 | 已处理告警占比 |

### 图表说明

- **运行状态分布**：饼图展示运行中/停运/检修设备比例
- **电压等级分布**：柱状图展示各电压等级设备数量
- **告警统计**：展示各级别告警数量
- **负载趋势**：24小时负载变化曲线
- **台区分布**：按变电站统计台区数量

| 优先级 | 高/中/低 |
| 状态 | 待审批/已批准/执行中/已完成 |

| 字段 | 说明 |
|------|------|
| 任务编号 | 巡检任务唯一标识 |

## 分析计算

分析计算模块提供电网运行分析的专业计算功能。

### 模块列表

#### 1. 线损分析

分析输电线路的电能损耗情况。

| 指标 | 说明 |
|------|------|
| 供电量 | 线路输入电量 |
| 售电量 | 线路输出电量 |
| 损耗 | 电能损耗量 |
| 线损率 | 损耗/供电量 × 100% |

**线损率判断标准**：
- ≤ 5%：正常（绿色）
- 5% ~ 10%：偏高（黄色）
- > 10%：高损（红色）

#### 2. 负荷预测

预测未来负荷变化趋势。

| 字段 | 说明 |
|------|------|
| 目标名称 | 预测对象 |
| 预测类型 | 短期/中期/长期 |
| 预测值 | 预测负荷（MW） |
| 实际值 | 实际负荷（MW） |
| 误差率 | 预测误差百分比 |
| 算法 | 预测算法 |

#### 3. 潮流计算

计算电网潮流分布。

| 字段 | 说明 |
|------|------|
| 计算名称 | 计算任务名称 |
| 节点数 | 电网节点数量 |
| 支路数 | 电网支路数量 |
| 总发电 | 总发电功率（MW） |
| 总负荷 | 总负荷功率（MW） |
| 总损耗 | 总损耗功率（MW） |
| 状态 | 计算中/计算完成/计算失败 |

#### 4. N-1 校验

进行 N-1 安全校验。

| 字段 | 说明 |
|------|------|
| 校验名称 | 校验任务名称 |
| 总项数 | 校验项目总数 |
| 通过项 | 通过校验的项目数 |
| 失败项 | 未通过校验的项目数 |
| 风险等级 | 高风险/中风险/低风险 |
| 风险评估 | 风险详细分析 |

#### 5. 设备健康

评估设备健康状态。

| 字段 | 说明 |
|------|------|
| 设备名称 | 设备标识 |
| 设备类型 | 变压器/断路器/线路等 |
| 健康得分 | 0-100 分 |
| 健康等级 | 优秀/良好/一般/较差 |
| 风险等级 | 高风险/中风险/低风险 |
| 运行年限 | 设备投运年限 |
| 建议 | 运维建议 |

**健康得分判断标准**：
- ≥ 90：优秀（绿色）
- 60 ~ 90：良好/一般（黄色）
- < 60：较差（红色）

#### 6. 可靠性分析

计算供电可靠性指标。

| 指标 | 全称 | 说明 |
|------|------|------|
| SAIDI | 系统平均停电持续时间 | 用户平均停电时间（分钟/户） |
| SAIFI | 系统平均停电频率 | 用户平均停电次数（次/户） |
| ASAI | 平均供电可用率 | 供电可靠率（%） |

| 字段 | 说明 |

- 查看文档：点击文档卡片查看详情

### 2. 视频监控

| 字段 | 说明 |

| 状态 | 在线/离线 |

- 查看实时画面

- 一键生成所有数据
- 单独生成指定类型数据

## 告警系统

告警系统实时监控电网运行状态，自动检测异常并生成告警。

### 告警类型

| 类型 | 说明 |
|------|------|
| 设备离线 | 设备通信中断 |
| 电压异常 | 电压超出正常范围 |
| 温度过高 | 设备温度超过阈值 |
| 过载告警 | 负载率超过阈值 |
| 故障告警 | 设备故障告警 |
| 检修提醒 | 计划检修提醒 |

### 告警级别

| 级别 | 颜色 | 说明 |
|------|------|------|
| 严重 | 🔴 红色 | 需立即处理 |
| 高 | 🟠 橙色 | 需尽快处理 |
| 中 | 🟡 黄色 | 需关注 |
| 低 | 🟢 绿色 | 一般提醒 |

### 告警状态

| 状态 | 说明 |
|------|------|
| 活动中 | 告警正在发生 |
| 已确认 | 告警已被确认 |
| 已解决 | 告警已处理完成 |

### 操作说明

1. **查看告警**：点击告警列表中的告警项
2. **定位设备**：点击定位按钮，地图跳转到告警设备位置
3. **确认告警**：点击确认按钮，标记告警已知晓
4. **处理告警**：处理告警后，标记为已解决
